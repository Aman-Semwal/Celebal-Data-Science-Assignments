# 📊 Celebal Data Science Assignments

This repository contains my weekly assignments completed during my **Data Science Internship at Celebal Technologies**. The assignments focus on building practical skills in **Python, Data Analysis, Machine Learning, Deep Learning, and Generative AI** through hands-on projects and real-world datasets.

---

## 📌 Repository Overview

The repository is organized week-wise, with each folder containing the corresponding assignment, notebooks, datasets (if required), and supporting files.

---

## 📚 Weekly Assignments

### 📅 Week 1 – Python Fundamentals
- Python syntax and programming basics
- Variables, data types, and operators
- Conditional statements and loops
- Functions and modules
- File handling and exception handling
- Object-Oriented Programming (OOP)

### 📅 Week 2 – Data Analysis with NumPy & Pandas
- NumPy arrays and operations
- Data manipulation using Pandas
- Data cleaning and preprocessing
- Handling missing values and duplicates
- Reading and writing CSV/Excel files
- Exploratory Data Analysis (EDA)

### 📅 Week 3 – Data Visualization & Statistics
- Data visualization using Matplotlib and Seaborn
- Descriptive statistics
- Probability concepts
- Correlation and covariance
- Distribution analysis
- Extracting insights from data

### 📅 Week 4 – Machine Learning Fundamentals
- Supervised vs Unsupervised Learning
- Feature engineering and preprocessing
- Regression algorithms
- Classification algorithms
- Model evaluation metrics
- Train-test split and cross-validation

### 📅 Week 5 – Customer Intelligence System
- Customer segmentation
- K-Means clustering
- DBSCAN clustering
- Principal Component Analysis (PCA)
- Cluster profiling
- Business insight generation

### 📅 Week 6 – CIFAR-10 Image Classification
- Image preprocessing
- Artificial Neural Networks (ANN)
- Convolutional Neural Networks (CNN)
- Model training and evaluation
- Performance comparison between ANN and CNN
- Accuracy and loss analysis

### 📅 Week 7 – Retrieval-Augmented Generation (RAG)
- Document loading and preprocessing
- Text chunking
- Embedding generation
- Vector database creation
- Semantic search
- Retrieval-Augmented Generation (RAG)
- LLM-powered Question Answering system
  
### 📅 Week 8 – Single Agent Systems & Agent Pipelines 
- Build a Single-Agent Smart Assistant that:
- Understands user queries
- Routes tasks based on intent
- Uses tools when required
- Returns structured JSON output

## 🚀 Getting Started

1. Clone the repository:

```bash

```

2. Navigate to the desired week's folder.

3. Open the notebook using:
   - Jupyter Notebook
   - VS Code
   - Google Colab

4. Install the required dependencies (if applicable):

```bash
pip install -r requirements.txt
```
